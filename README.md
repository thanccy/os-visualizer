# OS Visualizer – Round Robin CPU Scheduling

## Project Description
This project simulates the Round Robin CPU scheduling algorithm using Python. It visualizes process execution using Gantt charts and calculates CPU scheduling performance metrics.

## Features
- Round Robin CPU scheduling simulation
- Gantt chart visualization
- Completion time
- Turnaround time
- Waiting time
- Response time
- Average performance metrics
- Context switching overhead simulation
- Comparison of different time quantums

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab / Jupyter Notebook

## Practical Activities
1. Round Robin scheduling without context switching overhead: quantum 2 ms vs. 3 ms.
2. Round Robin scheduling with 1 ms context switching overhead: quantum 2 ms vs. 4 ms.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install the required libraries if necessary:
   `pip install pandas matplotlib`
3. Run the notebook cells.
4. View the Gantt charts, scheduling metrics, and comparison tables.
